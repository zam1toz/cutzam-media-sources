# CutZam media engine sources and notices

Free corresponding sources and matching Windows x64 binaries for CutZam's
FFmpeg engine. This repository does not contain the proprietary CutZam editor.

Download the **CutZam-media-engine-sources-20261020.zip** asset from the
[versioned release](https://github.com/zam1toz/cutzam-media-sources/releases/tag/media-engine-20261020-lgpl). GitHub's automatic “Source code” links only archive
this small index repository, not the complete engine source kit.

The release also provides the matching runtime ZIP, original license notices,
source offer and SHA256SUMS.txt. No login, payment or software installation is
required to download source. Extract the source kit and read
`media-tools/build/README.txt`. Each component retains its own upstream license;
there is no blanket license replacing those terms.

FFmpeg uses LGPL 2.1 or later, FreeType uses the selected FreeType License, and
GCC runtime code is accompanied by its Runtime Library Exception. Full notices
and original archives are in the source kit. No GPL-only FFTW/Chromaprint code is
linked into the matching engine. No changes are made to upstream component code;
configuration selects the compiled subset. Compiler environments may change;
bit-identical rebuilds are not promised.

Please retain every released source archive and its matching runtime indefinitely,
and fulfill the written source offer for at least three years after its last
distribution. Contact: amsheep@myboool.com.
